## 整理优先级

1. CIS5800 三维视觉：先用本仓库完成复现，选择有实际质量的图、GIF 和指标；保留课程项目定位。
2. ROBA：整理本人负责的模块、系统结构、比赛视频、控制/感知接口和团队贡献。名次与参赛人数的表述应明确，不能把学生人数写成团队数。
3. 最优控制：提供模型、LQR/MPC 对比、轨迹/误差/控制输入曲线、固定实验配置和可运行入口。
4. 水果检测追踪：可发布部分整理成独立 repo，标明数据、检测器、跟踪器、评价指标和个人贡献。未公开研究按导师/团队约定展示。
5. UR16e 与康复机器人：与目标岗位相关时做简洁项目页，展示模型、CAD/仿真或实物视频；不必全部做大型软件仓库。

## 每个重点项目的展示骨架

- 一句话：解决什么问题，输入/输出是什么。
- 15–30 秒视频或 GIF，加一张结构图。
- 个人贡献，和团队/课程提供内容分开说明。
- 运行命令、数据来源、依赖与环境。
- 2–3 个真实指标，说明数据划分和测量条件。
- 一个失败案例或限制，说明分析和改进。
- GitHub 链接与项目页；有真实论文时再加论文链接。

PhD/RA 版本突出实验问题、对照和分析；公司实习版本突出可运行代码、系统接口、性能和清晰演示。详尽资料放在 README/报告，主页保持简洁。

## 主页建议

把没有实际论文的 Placeholder publication 改为 Research in Progress 或移除假入口；保留真实状态，避免让读者误以为已经有 preprint。教育经历结束时间与简历同步。给重点项目加真实 Code/Demo 链接。作品数量可以少，但每项都能解释贡献并展示可靠结果。
